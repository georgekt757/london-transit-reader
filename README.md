# london-transit-reader

This program is to retrieve London rail transit data by reading from TfL's API, and then output it in a
neat, user-friendly format. It'll be able to get the status of London Underground, London
Overground, Docklands Light Railway, Elizabeth line, Trams, and London Cable Car services for the
user.
