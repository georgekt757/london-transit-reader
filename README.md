# london-transit-reader

This program is to retrieve London rail transit data by reading from TfL's API, and then output it in a
neat, user-friendly format. It'll be able to get the status of various services for the user. Which
services TBD, though it will definitely include London Underground, London Overground, and
Elizabeth line services.
